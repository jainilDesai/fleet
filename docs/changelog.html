Changelog

Every release of Fleet. Update with npm install -g @jainil_desai/fleet@latest.

0.1.0

10 October 2026

First public release.

  • Agents: every live Claude Code session on your Mac, grouped by repo, with status, model, branch, current tool call, cost including subagents, and context use. Each session's panel shows its subagent tree and workflow phases.
  • History: a record of every session (title, project, branch, model, cost, prompts, files edited) that stays after Claude Code deletes the transcript, with search and saved summaries.
  • Notifications: inbox, tab count and macOS banners when an agent needs you, finishes, or a subagent or workflow ends. With terminal-notifier installed, a banner opens the session's terminal tab when clicked.
  • New agent: starts claude in Terminal or iTerm through your login shell, with model, effort, permission mode, name, first prompt and an optional worktree.
  • Usage, MCP servers, plugins and skills, and plan limits through the statusline.
  • The Agents page warns when it can't read Claude Code's transcript format, instead of showing zeros.
  • Workflow journal files are no longer shown or counted as agents.
